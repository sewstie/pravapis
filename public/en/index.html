    A few good questions

    Is this a translator?

    No. Pravapis changes Belarusian orthography or script. It does not translate between languages or check general grammar.

    What is the difference between Łacinka for Narkamaŭka and Taraškievica?

    Łacinka preserves the selected spelling: снег → snieh, сьнег → śnieh. Choose the source and target orthographies, then enable Latin output. For transliteration only, select the same orthography in both lists.

    Which modes can I use?

    Convert Narkamaŭka to Taraškievica and back, with Cyrillic or Latin output. To transliterate without changing spelling, keep the same orthography and enable Latin output. Taraškievica follows the 2005 codification.

    Will every word be correct?

    Coverage is incomplete. This site uses the JavaScript engine, which omits the Python stress table; some context-sensitive не/без → ня/бяз forms can differ. Always review the output. Read the evaluation methodology and known limitations.

    What happens to my text?

    The JavaScript engine processes your text in your browser. No text is sent to a conversion server or put in URLs, analytics, or browser storage. Theme preferences are saved locally; text stays in memory when switching interface languages.
