БЕЛEN

Developer guide · English

Belarusian spelling.
In a few lines of code.

Use the JavaScript package in your own application, or explore the Python engine and its documented API.

01 — Install and convert

Requires Node.js 18 or newer. ESM, CommonJS, and TypeScript declarations are included.

$npm install pravapis
import { convert } from "pravapis";

const result = convert("Снег і план", {
  to: "taraskievica"
});
// → Сьнег і плян

The required to option is taraskievica or narkamauka. The result includes converted text, changes, direction, engine version, data version, and unresolved forms.

02 — Inspect the changes

for (const change of result.changes) {
  console.log(change.from, "→", change.to);
  console.log(change.rule, change.citation);
}

Change offsets refer to Unicode code points in the output. Use Array.from(result.text) before slicing by these offsets in JavaScript, especially around emoji.

03 — Work with scripts

import { transliterate } from "pravapis/translit";

transliterate("Беларусь", "lacinka");
// → Biełaruś

This package function changes script only. The website's “Convert + Łacinka” mode first converts orthography, then transliterates it. This website runs the pinned pravapis 0.1.1 JavaScript package, including the proper-name dictionary, inside a browser worker. No Python backend or conversion API is needed.

Documentation and scope

The engine uses dictionaries and spelling rules, following the 2005 classical spelling codification. It does not translate languages. The JavaScript package omits the Python stress table, so some stress-dependent не/без → ня/бяз forms differ. Review converted text and consult the evaluation methodology and the documented JavaScript gaps for scope and limitations.
